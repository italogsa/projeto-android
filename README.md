# Curiosidades de Tecnologia

Este projeto é um site informativo que apresenta curiosidades sobre o mundo da tecnologia, com foco em temas históricos e interessantes, como a origem do mascote do Android e a evolução das versões do sistema operacional.

## 📋 Funcionalidades

- **Cabeçalho com navegação**: Links para diferentes seções do site, incluindo "Home", "Notícias", "Curiosidades" e um link externo para contato no LinkedIn.
- **Conteúdo educativo**: Artigos detalhados sobre temas tecnológicos, com imagens, vídeos e listas interativas.
- **Rodapé personalizado**: Créditos ao criador original e ao desenvolvedor que recriou o site.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação do conteúdo.
- **CSS3**: Estilização do site.
- **Imagens e Multimídia**: Uso de imagens e vídeos para enriquecer a experiência do usuário.

## 🎯 Objetivo

Este projeto foi recriado como parte de um estudo prático de desenvolvimento web, com o objetivo de aplicar conhecimentos em HTML e CSS, além de explorar boas práticas de design e acessibilidade.
